# Healthy Meal Planner

## Project Overview
Healthy Meal Planner is an Android application that provides food suggestions based on the user's age, health condition, and available ingredients. It aims to make choosing suitable meals easier through a simple mobile interface.

## Problem Statement
Choosing suitable meals can be challenging when considering individual health conditions and the ingredients available at home. This application helps users explore food suggestions based on these inputs.

## Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Navigation Compose

## Key Features
- Enter age-related information.
- Select a health condition.
- Provide available ingredients.
- Get healthy food suggestions.
- View personalized dietary suggestions.

## Installation Instructions
1. Clone the repository:

   `git clone https://github.com/y-amrutha/HealthyMealPlanner.git`

2. Open Android Studio.
3. Select **Open** and choose the cloned project folder.
4. Allow Gradle to sync.
5. Run the application on a compatible Android device or emulator.
